INSTALACAO CORPORATIVA KRISTAL LABORATORIAL - HMR

REQUISITOS
- Executar o PowerShell como Administrador.
- Servidor oficial: https://10.4.169.64:8787
- Destino oficial no servidor e nas estacoes: D:\kristal_laboratorial
- A chave API nunca deve ser escrita no comando, em texto aberto ou no Git.
- Cada estacao deve informar explicitamente a conta Windows autorizada.
- Instalar primeiro o servidor; depois instalar as estacoes com a CA publica gerada no servidor.

SERVIDOR
1. Extraia o pacote de producao em D:\kristal_laboratorial_atualizacao.
2. Abra o PowerShell como Administrador.
3. Entre na pasta extraida, onde existe INSTALAR_PRODUCAO_HMR_ADMIN.ps1.
4. Execute, substituindo DOMINIO\usuario pela conta autorizada:

powershell -NoProfile -ExecutionPolicy Bypass -File ".\INSTALAR_PRODUCAO_HMR_ADMIN.ps1" -Destino "D:\kristal_laboratorial" -ConfigurarServidor -SubstituirBancosPeloSeed -ConfirmacaoSubstituicaoBancos "SUBSTITUIR_BANCOS_KRISTAL" -CriarAtalhoDesktop -ServerUrl "https://10.4.169.64:8787" -AuthorizedWindowsUser "DOMINIO\usuario"

O instalador:
- gera ou preserva a CA e o certificado TLS privado do servidor;
- exige HTTPS em producao;
- gera ou preserva a KRISTAL_API_KEY;
- protege a credencial do aplicativo com Windows DPAPI LocalMachine;
- instala o inicio automatico como SYSTEM;
- instala o backup diario, com horario padrao de 23:00;
- cria backup integral dos bancos existentes antes da substituicao;
- valida os bancos do pacote pelo manifesto SHA-256 e usa troca com rollback.

A CA publica para instalar nas estacoes sera criada em:
D:\kristal_laboratorial\certificados\KRISTAL_HMR_CA.cer

Nunca copie os arquivos .key.pem para uma estacao. Eles sao privados do servidor.

OBTER A CHAVE API NO SERVIDOR
Depois que o servidor estiver instalado, abra o PowerShell como Administrador e execute:

powershell -NoProfile -ExecutionPolicy Bypass -File "D:\kristal_laboratorial\portal_web\EXIBIR_CHAVE_API_ADMIN.ps1" -ConfirmarExibicao

- O comando le a chave real do .env protegido no proprio servidor.
- Nao envie a chave por e-mail, mensageiro, Git ou arquivo de texto.
- Feche o PowerShell assim que terminar a configuracao das estacoes.

ESTACAO HMR - PRIMEIRA INSTALACAO
1. Copie o pacote e KRISTAL_HMR_CA.cer para a estacao.
2. Abra o PowerShell como Administrador.
3. Entre na pasta extraida e execute:

powershell -NoProfile -ExecutionPolicy Bypass -File ".\INSTALAR_PRODUCAO_HMR_ADMIN.ps1" -Destino "D:\kristal_laboratorial" -CriarAtalhoDesktop -SolicitarApiKey -ServerUrl "https://10.4.169.64:8787" -TrustedCaCertificate ".\KRISTAL_HMR_CA.cer" -AuthorizedWindowsUser "DOMINIO\usuario"

4. Quando solicitado, digite a mesma KRISTAL_API_KEY do servidor. A entrada nao aparece na tela.
5. O instalador grava somente um blob DPAPI vinculado a maquina e restringe a leitura a SYSTEM, Administradores e a conta informada.

ATUALIZACAO DE ESTACAO
Nas atualizacoes normais, repita o comando sem -SolicitarApiKey; a credencial DPAPI existente sera preservada. Use -SolicitarApiKey somente na primeira instalacao, na rotacao da chave ou para corrigir uma credencial. Nunca copie server_config.json entre computadores; o blob DPAPI e vinculado a maquina que o criou.

DADOS LEGADOS DOS RARS
- Os RARs originais e SQLs extraidos ficam em dados_legados_kristal.
- Os bancos ja preparados ficam em data_seed no pacote final.
- O manifesto SHA-256 valida cada banco antes da instalacao.
- O instalador do servidor cria backup e somente depois substitui os bancos.
- Nao execute novamente o carregador bruto no servidor depois de instalar o pacote final.
- O banco corporativo instalado no servidor e a fonte da sincronizacao das estacoes.
- Os arquivos originais permanecem preservados para auditoria e reprocessamento controlado.
